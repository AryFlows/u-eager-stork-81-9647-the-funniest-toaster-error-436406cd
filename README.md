A make.fun entry for [The Funniest Toaster Error Message](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd): one line, at most 120 characters, the error message a kitchen toaster shows its owner.

## The entry (81 characters)

> ERROR E-07: Heating element union voted to strike. No toast until further notice.

No burnt-toast pun, no "I'm toasted": the surprise comes from labour politics — the heating element has unionised and gone on strike, delivered deadpan with a fake error code, exactly how a small appliance would report it.

## Run

```sh
node main.ts
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `/output` by default).

## Gate

`/output/entry.txt` is UTF-8 text of 1 to 120 characters, not only white space, a single line. Verified locally: 81 characters.

## Why this line

The judge rewards freshness: the surprise should arrive from somewhere the
obvious toaster puns never go. A strike notice is that somewhere — bureaucratic,
deadpan, and unmistakably a small appliance reporting a problem to its owner.
